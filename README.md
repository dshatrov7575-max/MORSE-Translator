# morse-translator

Бесплатный онлайн словарь-переводчик живой язык ↔ МОРЗЕ (русский, английский,
узбекский, таджикский) с речью и картинками; та же сборка — одним файлом
виртуальной машины для сети организации.

Контекст и полный план — файлы `HANDOFF_MORSE_ПЕРЕВОДЧИК_ГЛАВНАЯ1_*.md` и
`ПЛАН_ГРАФИК_MORSE_5_НАПРАВЛЕНИЙ_*.md` в Google Drive, папка
`Project_TechSense(Cloude)`. Это направление D общего плана; ведёт чат
«Главная1».

## Статус: этап D0 (скелет сборки)

Готово:
- Docker Compose: `model-server` (Ollama, OpenAI-совместимый API) +
  `morse-core` (FastAPI) + `gradio-ui` (Gradio).
- `morse-core`: эндпоинты `/translate`, `/check`, `/to_umr`, `/from_umr`,
  `/icons`, `/tts`, `/asr`. `/translate` и `/asr` — рабочие (без грамматики и
  без проверяльщика, см. ниже); `/check`, `/to_umr`, `/from_umr`, `/tts` —
  заглушки (501/503) до готовности грамматики (план A) и ядра (план B).
- Gradio: текст, микрофон → `/asr`, кнопка перевода → `/translate`, полоса
  картинок (пока пустая, подключается на D4).

Сознательно не сделано на D0 (см. план, раздел 0 «правило разделения»):
сторона МОРЗЕ не имеет нейросетевой реализации — `/check`/`/to_umr`/`/from_umr`
ждут правил из планов A и B, а не временной нейро-заглушки, чтобы не плодить
фальшивые «вроде работает» результаты.

## Запуск

```bash
cd morse-translator
docker compose up --build
```

- Gradio: http://localhost:7860
- morse-core: http://localhost:8001/docs (Swagger)
- Ollama: http://localhost:11434

Перед первым переводом загрузить модель в Ollama:

```bash
docker compose exec model-server ollama pull qwen3:4b
```

## Замер скорости (без видеокарты)

Скрипт `scripts/speed_test_lm_studio.py` — для машины разработчика (LM Studio,
CPU, без видеокарты). Меряет Qwen3-4B и Qwen3-8B в GGUF: вход ~1 КБ русского
текста, выход — токены/сек и секунды на 1 КБ. Результат — отчёт
`MORSE_TRANSLATOR_SPEED_D0_<дата>.md`.
