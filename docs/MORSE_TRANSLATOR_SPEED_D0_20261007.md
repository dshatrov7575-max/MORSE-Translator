# Замер скорости — MORSE-переводчик, этап D0 (07.10.2026)

Машина: LM-STUDIO (разработчик), Intel Core i5-13400F, Python 3.12.10,
LM Studio (`lms` CLI). Вход — тот же текст на русском (~1800 байт, пример
про насосную станцию, в духе примеров D1–D5 из TechSense), задача модели —
краткий пересказ своими словами.

**Важное отличие от плана:** на машине обнаружена видеокарта NVIDIA GeForce
RTX 5060 — раздел 3 исходного HANDOFF исходил из «видеокарты пока нет».
Судя по всему, владелец её уже приобрёл. Ниже — два замера: как модель
ведёт себя по умолчанию (с видеокартой) и принудительно без неё
(`--gpu off`), чтобы точка «без видеокарты» из плана осталась с реальным
числом.

## Результаты

| Модель | Режим | Токены вывода | Время | Токенов/сек | Сек. на 1 КБ входа |
|---|---|---|---|---|---|
| Qwen3-8B Q4_K_M | с видеокартой (авто) | 683 | 12.82 с | 53.27 | 7.29 |
| Qwen3-8B Q4_K_M | без видеокарты (`--gpu off`) | 524 | 74.59 с | 7.02 | 42.43 |
| Qwen3-4B Q4_K_M | — | — | — | — | загрузка ещё идёт на момент записи |

Для сравнения — оценка из плана («на процессоре — 5–20 токенов в секунду,
10–60 секунд на 1 КБ»): замер без видеокарты (7.02 ток/с, 42.43 с/КБ)
попадает точно в этот диапазон. С видеокартой — почти в 8 раз быстрее.

## Что это значит для решения владельца №4 (план, раздел 8)

Исходное решение «движок без видеокарты — Ollama/llama.cpp, LM Studio —
только у разработчика» не меняется: для виртуальной машины заказчика
ориентир остаётся «без видеокарты». Но раз у разработчика видеокарта
появилась — замеры с ней дают реальную верхнюю границу скорости для версии
«заказчик с видеокартой» (раздел 8, вопрос 4), и их можно использовать в
показе партнёрам вместо прикидок.
